# Pink Music

SillyTavern(酒馆)音乐插件:简约界面、三套配色、悬浮球、悬浮歌词,支持网易云音乐 / QQ 音乐账号。

> **免责声明**
> 本项目仅供个人学习和交流使用,不提供、不存储、不分发任何音乐资源。
> 使用的是网易云音乐、QQ 音乐的**非官方**接口,与这两个平台没有任何关系,接口随时可能失效。
> 你需要用自己的账号登录,并自行遵守相关平台的服务条款和当地法律法规。

## 功能

- 悬浮球:显示封面和播放进度,可拖动,松手吸附到屏幕左右边缘
- 悬浮歌词:多行滚动(固定 3 行)或单行跑马灯,可拖动、锁定,可调字号、文字颜色、背景颜色和透明度
- 5 套主题:黑、白、粉、淡粉白、淡蓝白
- 网易云:扫码登录、读取「我喜欢的音乐」和自己的歌单、喜欢 / 取消喜欢
- QQ 音乐:Cookie 登录、搜索、播放、歌词
- 播放顺序:列表循环 / 单曲循环 / 随机 / 顺序播放
- 智能过渡(淡入淡出,实验性,默认关闭)
- 锁屏 / 控制中心的播放控制(Media Session)

## 安装

本插件分两部分,**都要装**。下面的 `<酒馆目录>` 指 SillyTavern 的根目录(里面有 `config.yaml` 的那个文件夹)。

### 1. 前端扩展

在酒馆里打开「扩展」→「安装扩展」,粘贴本仓库的 GitHub 地址,安装即可。

也可以手动安装:把本仓库里的 `manifest.json`、`pink-music-ui.js`、`pink-music-ui.css` 三个文件放进
`<酒馆目录>/public/scripts/extensions/third-party/pink-music/`。

### 2. 后端插件

1. 把本仓库里的 `pink-music-server` 整个文件夹复制到 `<酒馆目录>/plugins/`
2. 在 `<酒馆目录>/plugins/pink-music-server` 里打开终端,运行:`npm install`
3. 打开 `<酒馆目录>/config.yaml`,把 `enableServerPlugins` 改成 `true`
4. 重启酒馆,刷新浏览器(Ctrl+F5)

启动时酒馆控制台出现 `[pink-music] 后端已加载` 就说明后端正常。

## 使用

- 点悬浮球打开面板:「搜索」「歌单」「账号」「外观」四个标签
- 网易云扫码要用**另一台设备**的网易云 App 扫,建议在电脑上打开酒馆完成登录
- QQ 音乐需要从浏览器复制 Cookie:电脑上登录 y.qq.com,按 F12 打开「网络」,刷新后点任意请求,复制请求头里的 Cookie

## 关于登录信息

登录信息保存在你自己电脑上的 `<酒馆目录>/data/_pink-music/auth.json`(明文)。
**不要把这个文件、也不要把整个 `data` 文件夹发给别人或上传到网上。**

## 常见问题

- **没有悬浮球**:检查前端三个文件是不是直接在 `pink-music` 文件夹里,不要多套一层;扩展列表里要勾选启用
- **提示后端插件没有加载**:确认 `enableServerPlugins: true`,并重启了酒馆
- **提示缺少网易云依赖**:在 `plugins/pink-music-server` 里运行 `npm install`
- **一直显示「正在获取播放地址」**:看酒馆控制台里 `[pink-music]` 开头的日志。网易云可能暂时限制了请求(code -460),过一会儿再试或换个网络
- **iPhone 锁屏就停播**:关闭「智能过渡」,并刷新页面。iOS 会掐断走 Web Audio 的声音
- **VIP / 无版权的歌放不出来**:这是平台限制,不是插件问题

## 已知限制

- QQ 音乐暂时没有歌单和喜欢功能,只支持 Cookie 登录
- 非官方接口,随时可能失效
- 「智能过渡」只是淡入淡出,不是网易云那种节奏分析;iPhone 上开启后后台可能停播
